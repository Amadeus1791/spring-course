# Spring and Spring Boot: course code

Open this folder once in IntelliJ (File, Open, this folder). You see the labs and the playground.
The bank app is the trainer's demo: you see its code on the slides.

## The labs

One project per module (`module1`): one package per lab (`labs.lab1_1`, ...),
one package per task, each task with its own `Main` (in `module2-boot`, lab 2.4: `CardApplication`).
Every task stands alone: start it, finish it, or skip it. Run a task with the green arrow next to its `main`.
Places to change carry `TODO Lab X.Y` (TODO window: Alt+6). The lab booklet shows what a finished task prints.

## The documents

`documents/` holds the slides, the lab booklet and the reference sheet of every module released so far.
After a lab has been discussed, its debrief deck appears there and its solution under `solutions/`.

## The playground

Small examples, one project per module (`module1`), inside it one
package per chapter and one per example, in the order of the slides. Every example has a `main` you can run.
